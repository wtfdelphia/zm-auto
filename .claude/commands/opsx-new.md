# /opsx:new — 创建 OpenSpec 变更

创建新的 OpenSpec change，进入 proposal/design/tasks 工件创建流程。

对应项目内 Skill: `openspec-new-change`

## 执行

1. 读取 `AGENTS.md`、`spec/design.md`
2. 使用 `openspec new change "<name>"` 创建变更目录
3. 按 spec-driven schema 依次创建 proposal.md、design.md、tasks.md
4. 如涉及 capability 变化，创建 delta specs
